# ai-logs

Диалоги с агентами пишутся автоматически хуками Codex (`.codex/hooks.json`) и Claude Code
(`.claude/settings.json`) через `tools/ai_log.py`. Руками этот каталог не редактируется.

- `PROMPTS.md` — все мои промпты по времени, с этапом таймера (`Реализация с AI › Ключевые ручки · T+42:10`)
  и ссылкой на сессию.
- `sessions/*.md` — полные сессии: промпт → финальный ответ агента.

Секреты (API-ключи, JWT, пароли из `.env`, email из git config, домашний путь) маскируются
при записи; `make finish` дополнительно проверяет репозиторий перед commit.
