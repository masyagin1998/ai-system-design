> ### Нефункциональные требования

### Codex · 20:35 · Реализация с AI · T+75:38

Рабочие ручки:

**Авторизация**

- `POST /api/v1/auth/register` — регистрация `{email, password}`.
- `POST /api/v1/auth/token` — получить Bearer-токен.
- `GET /api/v1/auth/me` — проверить токен.

**Пользователи и подписки** — нужны Bearer-токен.

- `GET /api/v1/users/{user_id}` — получить пользователя.
- `GET /api/v1/users/{user_id}/followers` — список подписчиков.
- `GET /api/v1/users/{user_id}/following` — список подписок.
- `POST /api/v1/users/{user_id}/followers` — подписаться.
- `DELETE /api/v1/users/{user_id}/followers` — отписаться.

**Посты и лента** — нужны Bearer-токен.

- `POST /api/v1/posts` — multipart-запрос с `file` и необязательным `text`; фото сохраняется в RustFS.
- `GET /api/v1/posts/{post_id}` — получить пост.
- `PUT /api/v1/posts/{post_id}` — обновить `text` и/или заменить `file`.
- `DELETE /api/v1/posts/{post_id}` — удалить пост.
- `GET /api/v1/feed?cursor=&limit=20` — получить страницу ленты.

Также работают шаблонные ручки `POST /api/v1/files`, `GET /api/v1/files/{key}`, CRUD-поиск items под `/api/v1/items` и проверки `GET /health`, `GET /health/async`.

```bash
curl -X POST http://localhost:8000/api/v1/auth/token \
  -H 'Content-Type: application/json' \
  -d '{"email":"user@example.com","password":"[REDACTED:kv]"}'
```

Затем подставьте токен и ID пользователя, чью ленту хотите получить:

```bash
curl http://localhost:8000/api/v1/users/2/feed \
  -H 'Authorization: Bearer ВАШ_ТОКЕН'
```
