## Prod → MVP
<!-- Оставить только релевантные строки; остальные удалить. -->
| В дизайне (prod) | В MVP | Почему можно сейчас | Как вернуть |
|---|---|---|---|
| Elasticsearch + CDC (Debezium → Kafka) | PostgreSQL + pg_trgm (GIN) | малый объём, поиск по 1–2 полям | CDC → Kafka → ES, контракт API тот же |
| Kafka / RabbitMQ + outbox | таблица `jobs` + пул воркеров (`FOR UPDATE SKIP LOCKED`), запись в той же транзакции | сотни задач/с хватает | outbox relay → Kafka, партиции по ключу |
| Микросервисы | один сервис + worker | один деплой, одна БД | вынести модуль по границе API |
| Шардирование / реплики PostgreSQL | один инстанс | объём демо | шардинг по `<ключ>`, read replicas |
| Redis Cluster / Sentinel | один Redis без персистентности | кэш можно потерять | кластер + реплики |
| S3 | RustFS (тот же S3 API) | локально | сменить endpoint |
| OAuth2 / SSO | нет / JWT без пароля | не цель демо | OIDC-провайдер |
| WebSocket / push | polling GET | проще | WS/SSE-шлюз + pub/sub |
| ClickHouse / аналитика | SQL-агрегаты в PostgreSQL | мало данных | CDC → ClickHouse |
| Внешние сервисы | заглушка | нет доступа | клиент + ретраи + circuit breaker |
| Rate limiting на gateway | Redis INCR + EXPIRE | достаточно для демо | API gateway |
| CDN | отдача файлов через API | один клиент | CDN перед S3 |
