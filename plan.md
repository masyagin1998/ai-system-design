## 1. Демо (happy path)

1. Зарегистрироваться по email + пароль → `201`, `id`; войти → `access_token`.
2. Создать item с токеном → `201`, `status=new`; через секунду `status=processed`.
3. Найти item по подстроке → он в списке.
4. Загрузить файл → `key`; скачать по `key` → то же содержимое.

## 2. PostgreSQL

<!-- SQL переносится в app/models.py один-в-один. Связи — через REFERENCES. -->

```sql
-- уже есть в коде (app/models.py)
CREATE TABLE users (
    id            BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    email         VARCHAR(255) NOT NULL UNIQUE,
    password_hash VARCHAR(200) NOT NULL,  -- scrypt: salt$hash
    created_at    TIMESTAMPTZ  NOT NULL DEFAULT now()
);

CREATE TABLE items (
    id         BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id    BIGINT       NOT NULL REFERENCES users (id) ON DELETE CASCADE,
    title      VARCHAR(200) NOT NULL,
    status     VARCHAR(20)  NOT NULL DEFAULT 'new',  -- new → processed
    created_at TIMESTAMPTZ  NOT NULL DEFAULT now()
);
CREATE INDEX ix_items_user_id ON items (user_id);
CREATE INDEX ix_items_title_trgm ON items USING gin (title gin_trgm_ops);  -- ILIKE '%q%'
```

## 3. HTTP API (`/api/v1`)

<!-- 🔒 — нужен заголовок Authorization: Bearer <token> (CurrentUser). -->

- `POST /api/v1/auth/register` `{email, password}` → `201 {id, email}`; `409` email занят — уже есть
- `POST /api/v1/auth/token` `{email, password}` → `200 {access_token, token_type}`; `401` — уже есть
- `GET /api/v1/auth/me` 🔒 → `200 {user_id}` — уже есть
- `POST /api/v1/items` 🔒 `{title}` → `201 {id, user_id, title, status, created_at}`; `422`
- `GET /api/v1/items/{id}` → `200 {…}`; `404`
- `GET /api/v1/items?q=&cursor=&limit=20` → `200 [{…}]`, сортировка `id DESC`
- `POST /api/v1/files` multipart `file` → `201 {key}`
- `GET /api/v1/files/{key}` → `200` содержимое файла; `404`

## 4. Важные нюансы

<!-- Только решения, влияющие на код: транзакции, задачи (kind и payload), кэш, файлы, статусы. -->

- Создание item и задача `item.created {item_id}` — в одной транзакции (`queue.enqueue`).
- Воркер `item.created` ставит `status=processed` и сбрасывает кэш item.
- `GET /items/{id}` — cache-aside в Redis на 60 с.
- Нарушение UNIQUE/FK → `409` (общий обработчик в `app/main.py`).
